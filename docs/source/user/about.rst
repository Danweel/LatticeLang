About LatticeLang
=================

LatticeLang is (ideally) a modular, extensible tool for constructing naturalistic
conlangs specifically. The goal is to make conlang creation more accessible while
providing enough depth for serious language designers.

Philosophy
----------

**Accessibility First**:
   - The interface should be intuitive enough for hobbyists while remaining flexible for experts.

**Modularity**:
   - Each component (phonology, morphology, orthography) can be
     developed, tested, and extended independently. This makes the codebase easier
     to maintain and contributes to long-term sustainability.

**Open Source**:
   - We encourage community contributions and believe in transparent development.

**Naturalism**:
   - Algorithms are based in linguistic principles and aim to produce plausibly
     naturalistic results, incorporating phonotactic constraints,
     sonority observations and other observable patterns from linguistics.

History
-------

LatticeLang was created by Daniil Woodland (Danweel) as a project to
attempt to apply more logic rules than normally offered by current word
generators, introduce a reverse version that can determine what your current
words are made of and generate more, and generally help conlangers  determine
and remember thier creative choices.

The project draws inspiration from:

- SIL FieldWorks, in particular glossing organization.
- PolyGlot, VulgarLang, the classic Gen, and many others.
- Various Python NLP libraries, etc.
