Community Index

conlang community, linguists, and language enthusiasts.

Contributing
------------

LatticeLang is in active development. Contribution guidelines will be
published here once the project reaches a stable release.

Planned contribution areas include:

- **Language presets** — Pre-built phonology configurations for natural
  languages
- **IPA data corrections** — Fixes or additions to the phoneme reference
  data
- **Documentation improvements** — Corrections, clarifications, or new
  examples
- **Code contributions** — Bug fixes, new constraint types, GUI work

.. note::

   The project is not yet accepting external contributions. This page
   will be updated when contribution workflows are ready. See
   :ref:`questions` for current development status.
